Skills, with receipts

Each one is something I have actually shipped and can talk through in detail.

Cloud Engineering — AWS

Moved Northlight’s web tier from a single EC2 box to ECS Fargate behind CloudFront: infrastructure defined in Terraform, secrets in SSM, blue/green deploys. Cold-start incidents went from monthly to none, and the monthly bill dropped about 30% after right-sizing tasks and adding S3 lifecycle rules. I also run the on-call rotation for it.

Frontend Architecture

I own the structure of two production React codebases — routing, data-fetching boundaries, and where state is allowed to live. On Nightcall I replaced a tangle of context providers with query-cache boundaries, which cut the initial bundle by 210KB and made the schedule view load in under a second on hospital wifi.

Design Systems

Built and maintain the component library four squads ship on: 46 components, tokens generated from Figma variables, visual regression on every PR. Adoption is measurable — 82% of new screens use it untouched, and UI bug reports fell by roughly a third in the two quarters after launch.

Leadership & Mentoring

I led a three-person squad through the Cassia scheduling rewrite: I wrote the plan, split it so each person owned a vertical slice, and ran a 30-minute weekly review that ended with decisions rather than notes. We shipped a week early. Both juniors I mentored there now lead features of their own — that’s the part I’d point to.

CI/CD & Release Engineering

Set up the GitHub Actions pipeline the team deploys through: typed checks, Playwright suite on preview URLs, one-command rollback. Deploys went from a scheduled Thursday-night event to roughly nine a week, with change-failure rate under 5%.

Accessibility

Led the audit that took Cassia Health to WCAG 2.1 AA — keyboard paths, focus order, contrast, and screen-reader labels across 40 screens — then wrote the lint rules and checklist that keep it from regressing. I test with VoiceOver, not just automated tooling.
